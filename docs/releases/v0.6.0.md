# v0.6.0 — Agent Experience Release

Guided `raddle init` / `raddle start` and read-only `raddle doctor` sit above the
unchanged Forge contracts. Setup preserves modified skills and global runtime
configuration. Existing v0.4.x/v0.5.0 contracts and independent loop ledgers need
no migration.

Validated locally on macOS with Python 3.12.11:

- Complete `task ci`: 98 tests passed, 5 optional GPU tests skipped; lint,
  strict mypy, evidence, Bandit, Trivy,
  hook/config checks and wheel/sdist builds.
- `task example`: external CPU workload accepted artifact and readback.
- Built wheel installed with uv into an isolated tool directory; initialization
  in a clean temporary project detected the real installed runtime and installed
  the complete bundle.
- Codex CLI 0.159.3 interactive smoke: native trust dialogs retained; welcome and
  workload/inspection choice; project investigation and target proposal; changes
  revised the target and required fresh approval; target approval preceded workload
  preflight, baseline/profile and a separate acceleration plan approval gate.
  Plan decline stopped candidate work and preserved baseline/profile evidence.
  No candidate or adoption was authorized in this smoke.

Supported: Codex and Claude Code with existing runtime backend/authentication.
Codex model overrides require its local catalog and supported effort; Claude
inherits model configuration and supports effort only when its CLI exposes the
flag. No Raddle model/provider fallback is added.

Limits: no explicit new OpenRouter/local/compatible-endpoint routing; native
backend inheritance does not verify third-party model compatibility. Claude's
interface was checked against installed help and exercised through mocked launch
tests, not a live model session. Native questions depend on actual tool/mode
availability; Codex smoke used conversational approval fallback. GPU tests skip
when local CUDA is unavailable. Provider/driver discovery is not proof of actual
model/library execution; preflight leaves those requirements NOT CHECKED until
approved workload probes verify them. No hosted website, remote VM, historical
ledger, external workload repository or published benchmark was changed.
